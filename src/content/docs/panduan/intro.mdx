Selamat datang di Dashboard Backstage **kitaloket.com**. Panduan ini disusun untuk membantu Anda (Vendor) mengelola seluruh rangkaian acara secara mandiri.

## Persyaratan Akun Vendor

Sebelum dapat membuat event, pastikan Anda telah menyiapkan dokumen berikut untuk proses verifikasi:

1. **Identitas Diri (KTP/Passport):** Sesuai dengan nama penanggung jawab.
2. **Rekening Bank:** Digunakan untuk pencairan hasil penjualan tiket.
3. **Legalitas (Opsional):** Dokumen perusahaan jika Anda mendaftar sebagai entitas legal.
4. **Email Aktif:** Pastikan email yang digunakan dapat diakses untuk keperluan komunikasi dan keamanan akun.
5. **Nomor Telepon Aktif:** Nomor yang dapat kami hubungi.

---

## Langkah Pendaftaran

### 1. Registrasi Akun

Akses halaman [Register Vendor kitaloket](https://kitaloket.com/auth/register-vendor), lalu isi formulir pendaftaran dengan data yang valid.

### 2. Melengkapi Profil

Pastikan anda melengkapi data profil EO Anda. Data ini akan tampil pada halaman publik setiap event yang Anda buat.

---

### Verifikasi Akun

Setelah mendaftar, Kami perlu melakukan verifikasi terhadap data yang Anda berikan. Pastikan Anda memeriksa email secara berkala untuk instruksi lebih lanjut. Kami juga dapat menghubungi Anda melalui nomor telepon yang terdaftar.

## Dashboard Overview

Setelah berhasil anda berhasil mendaftar dan memiliki akun yang terverifikasi, Anda dapat mengunjungi halaman dashoard, dan anda akan melihat beberapa menu utama:

| Menu              | Fungsi                                                          |
| :---------------- | :-------------------------------------------------------------- |
| **Ringkasan**     | Ringkasan performa event dan penjualan tiket.                   |
| **Event**         | Memantau, membuat, dan mengedit detail acara.                   |
| **Order**         | Memantau transaksi yang terjadi.                                |
| **Tiket**         | Melihat dan mengelola tiket event.                              |
| **Penjualan POS** | Mengelola penjualan tiket secara offline jika telah diaktifkan. |

## Tahap Selanjutnya

Setelah akun siap, Anda dapat melanjutkan ke tahap **[Membuat Event Pertama Anda](/panduan/buat-event)**.
