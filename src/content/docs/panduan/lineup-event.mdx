---
title: Kelola Lineup Event
description: Panduan mengatur daftar pengisi acara (lineup) untuk event di kitaloket.com
---

Menu **Lineup** digunakan untuk menampilkan siapa saja yang akan mengisi acara Anda. Anda dapat menggunakan database lineup yang sudah ada atau membuat baru secara spesifik untuk event tersebut.

Akses menu ini melalui **Menu Kelola > Lineup**.

## 1. Menambahkan Lineup

Terdapat dua cara untuk menambahkan pengisi acara ke dalam event Anda:

### A. Pakai Lineup Existing (Database Master)

Jika pengisi acara tersebut sudah pernah tampil di event kitaloket sebelumnya, Anda cukup mencarinya di kolom **Pilih dari master lineup**.

- **Keuntungan:** Data profil dan foto artis akan otomatis terisi sesuai database pusat.
- **Cara:** Ketik nama artis, pilih dari hasil pencarian, lalu klik Tambah.

### B. Buat Lineup Baru

Gunakan opsi ini jika pengisi acara belum terdaftar di sistem kami.

- **Nama Band / Artis:** Masukkan nama lengkap pengisi acara (Maksimal 30 karakter).
- **Foto (Opsional):** Unggah foto profil pengisi acara.
  - **Ketentuan:** Ukuran maksimal file adalah **500 KB**.
  - **Format:** Disarankan rasio kotak (1:1) untuk tampilan terbaik.

Klik tombol **Tambah Lineup** untuk memasukkannya ke daftar aktif event.

---

## 2. Mengatur Daftar Lineup

Setelah lineup ditambahkan, mereka akan muncul di bagian **Daftar Lineup di [Nama Event Anda]**.

- **Urutkan Lineup:** Anda dapat mengubah urutan tampil artis dengan melakukan _drag & drop_ pada ikon titik enam di sisi kiri nama artis. Jangan lupa klik **Simpan Urutan** setelah selesai melakukan perubahan.
- **Hapus Lineup:** Jika terjadi pembatalan pengisi acara, Anda dapat menghapusnya dari daftar event dengan mengklik tombol **Hapus** di sisi kanan nama artis.

---

:::caution[Catatan QA: Optimasi Gambar]

- **Batas 500 KB:** Pembatasan ukuran foto lineup bertujuan agar halaman event tetap ringan saat diakses melalui perangkat mobile dengan koneksi terbatas.
- **Konsistensi Data:** Menggunakan "Lineup Existing" sangat disarankan untuk menjaga konsistensi data artis antar-event di platform kitaloket.com.
  :::
