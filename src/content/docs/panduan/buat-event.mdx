---
title: Membuat Event Baru
description: Panduan langkah demi langkah mengisi formulir pembuatan event di kitaloket.com
---

Halaman ini menjelaskan cara mengisi formulir **Buat Event Baru** agar acara Anda tampil profesional dan informatif bagi calon pembeli. **Buat Event Baru** dapat diakses melalui menu **Event &rarr; Buat Event Baru** di dashboard Vendor Anda.

Untuk membuat event baru, lengkapi beberapa bagian berikut:

## 1. Informasi Dasar

Bagian ini adalah identitas utama acara Anda.

- **Nama Event:** Masukkan judul acara yang singkat dan jelas.
- **Slug (URL):** Alamat unik untuk halaman event Anda (misal: `kitaloket.com/event/nama-konser`). Sistem akan mengisinya secara otomatis, namun Anda dapat menyesuaikannya. **Sebaiknya slug tidak diubah setelah event dipublikasikan**, guna menjaga konsistensi tautan bagi pembeli.
- **Kategori:** Pilih kategori yang paling relevan agar memudahkan calon pembeli menemukan acara Anda.
- **Deskripsi Lengkap:** Gunakan editor teks untuk menjelaskan detail acara.

---

## 2. Media & Visual

Aspek visual sangat krusial untuk menarik minat pembeli.

- **Thumbnail Utama:** Gambar poster acara (Rekomendasi rasio 2:1).
- **Denah Tiket (Seating):** Unggah gambar denah tempat duduk jika acara Anda memiliki pengaturan tempat duduk khusus. Denah ini akan muncul di halaman pemilihan tiket oleh pembeli.
- **Denah Tiket Reguler:** Jika anda menggunakan tiket reguler (tanpa tempat duduk khusus), anda dapat mengunggah denah umum lokasi acara. Denah ini akan muncul di halaman daftar tiket.
- **Meta Deskripsi (SEO):** Ringkasan singkat 160 karakter yang akan muncul saat link acara dibagikan di media sosial (WhatsApp/Instagram).

---

## 3. Waktu & Lokasi

Pastikan data lokasi akurat untuk memudahkan pengunjung datang ke tempat acara.

- **Lokasi / Venue:** Nama gedung atau tempat spesifik.
- **URL Google Maps:** Masukkan link peta lokasi untuk disematkan di halaman event.
- **Zona Waktu:** Pastikan zona waktu (WIB/WITA/WIT) sesuai dengan lokasi pelaksanaan.

---

## 4. Konfigurasi Penjualan

Bagian ini mengatur kapan dan bagaimana tiket Anda dapat dibeli.

- **Mode Penjualan:**
  - _Selalu Dibuka:_ Tiket aktif segera setelah dipublikasikan.
  - _Selalu Tutup:_ Tiket tidak dapat dibeli hingga Anda mengubah statusnya.
  - _Ikuti Jadwal:_ Tiket hanya bisa dibeli pada rentang waktu mulai dan akhir penjualan yang Anda tentukan.
- **Maks. Tiket Per Sesi:** Batasi jumlah tiket yang dapat dibeli dalam satu kali transaksi.
- **Metode Batas Beli**:
  - _Per Sesi Checkout:_ Batas pembelian diterapkan setiap kali pembeli melakukan transaksi. **Misal**: jika batas 5 tiket, pembeli dapat membeli 5 tiket setiap kali mereka melakukan checkout. Hal ini memungkinkan pembeli melakukan pembelian berulang dengan maksimal 5 tiket per transaksi.
  - _Per Akun User:_ Batas pembelian diterapkan berdasarkan akun pembeli, terlepas dari berapa kali mereka melakukan transaksi. **Misal**: jika batas 5 tiket, pembeli hanya dapat membeli total 5 tiket untuk event tersebut, meskipun mereka melakukan beberapa kali checkout.

---

## 5. Media Sosial & Publikasi

Lengkapi link media sosial untuk membangun kepercayaan calon pembeli.

- **Sosial Media (Opsional):** Masukkan link Instagram, Facebook, atau kanal lainnya.
- **Status Publikasi:** \* **Draft:** Simpan perubahan tanpa memunculkannya di halaman utama.
  - **Publish:** Event langsung tayang secara publik.
- **Event Privat:** Jika dicentang, event tidak akan muncul di _homepage_ kitaloket.com dan hanya bisa diakses melalui link langsung.

---

:::caution[Catatan QA & Keamanan]

- **Verifikasi Event:** Sebelum event dapat dipublikasikan, kami akan melakukan verifikasi terhadap informasi event. Hal ini dilakukan guna memastikan event dijalankan sesuai dengan ketentuan platform dan kesepakatan yang ada.
- **Validasi Gambar:** Pastikan ukuran file gambar tidak terlalu besar (maks 800kb) untuk menjaga kecepatan _load_ halaman bagi pembeli.
- **Rasio Gambar:** Gunakan rasio yang direkomendasikan yaitu 2:1 untuk menghindari tampilan terpotong atau terdistorsi.
- **Review Informasi:** Periksa kembali semua informasi sebelum mempublikasikan event untuk menghindari kesalahan data.
  :::
